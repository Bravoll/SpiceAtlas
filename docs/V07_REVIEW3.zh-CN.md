# v0.7 第三次审查：来源、语言与动效修订

日期：2026-10-29。版本号仍是 0.7.0；不提交、不推送、不部署。上一轮说明保留，不改写其历史验证结果。

## 问题定位与最终行为

| 问题 | 原因 | 本轮处理 |
| --- | --- | --- |
| 主题延迟 | 整页 View Transition 捕获加上超大渐变、混合及裁切 | 当前输入事件立即应用颜色，只保留局部合成动画 |
| 文字重影／像幻灯片 | 原文仍显示，又覆盖文字副本；对整个正文使用模糊、裁切及位移 | 真实短文本的词／单字单元，表格和长文正常排版；有界、可取消 |
| Bing／Google 知识按钮只出现链接 | API 路由明确直接返回 external，没有执行检索读取 | 读取公开首屏结果，显示有标签的标题与摘要；审阅站点可继续在图鉴读取。已有资格的 Google 客户可用已配置的官方 JSON API |
| GBIF／NParks／ICAR 只显示说明 | 这些按钮原本只返回编辑说明；通用 HTML 又强制本地 DNS 成功 | 显式来源接入真实读取器；批准的 HTTPS 主机可交给已配置代理解析，仍拒绝私网地址及未知主机 |
| GBIF 结构不适配 | 旧平铺格式与新版 usage／classification 格式不同 | 首选 v2，兼容 v1；按实际标识生成 species 或 taxon 链接 |
| PlantNET 显示首页 | 物种名在斜体行，不能只取站点 title；名字出现在索引中也会被误认 | 识别具体分类名，校验 lvl/name 与描述；主页、索引和不匹配对象不作为文章 |
| Google／百度图片从未真正尝试内嵌 | 两个服务在代码中直接返回 can_try=False；本站 CSP 也只列 Bing | 对三家使用实际响应检测；来源不禁止时才尝试。可读的公开结果元数据可渲染为本地图集；不代理活动网页或移除安全头 |
| 界面换语言但正文仍是旧语言 | 自动缓存可先命中次选英文，掩盖尚未缓存的中文；异步回复还可能覆盖后来的选择 | 不让次选缓存掩盖已映射首选；语言保存排队、回复按代次判断，清除旧 Wiki 显式选择 |
| 维基语言选择重复／不完整 | 仅依赖目录中两个预存字段 | 英文页 langlinks 为锚；缺中文再独立搜索并校验学名／身份。Wiki 独立按钮＋语言选单，其他来源继续两行 |
| 加载完成突然归顶 | 进入条目的归顶在所有异步请求完成之后执行；一行 loading 也会压缩正文高度 | 点击时归顶，完成时不归顶；加载保留已有正文，提交渲染保存当时阅读位置 |
| 启动不自动开浏览器 | pythonw 环境的浏览器发现可能失败；控制台入口等待较短且受代理影响 | Windows 首选默认 Shell，再回退浏览器模块；回环就绪检测绕过代理并验证项目，最长等待 120 秒 |
| 日志不易翻到底部 | 只有 Text，没有可拖动的滚动条 | 加入右侧竖向滚动条和“跳到最新”，仍尊重用户暂停跟随旧日志的位置 |
| 点击标题只是重载并恢复旧状态 | 链接到根路径后，启动恢复又载入原来的选择 | 首页动作重置临时路径、筛选、来源及视窗至罗勒默认阅读；保留配置、收藏、历史和统计 |

点击已审阅检索结果的详情也进入阅读状态，可返回结果列表、再次前进；刷新详情不会误回到检索页。旧版其他来源包切换到 v2 缓存命名，避免继续命中已长期保留的错误首页，累计操作表和收藏不清空。

## 实际联网证据

- GBIF：欧芹通过 v2 取得结构化分类表。
- NParks：芫荽读取到约 12,867 字符 HTML、13 个章节。
- ICAR：孜然读取到约 2,665 字符 HTML、5 个章节。一轮冷请求约 21.8 秒，旧 8 秒预算明显不足。
- PlantNET：修正斜体分类标题后，芫荽物种描述约 6,500 字符，主页另行拒绝。
- 维基：从英文 Parsley 实测发现 113 个语言链接，中文为歐芹，另含日文、法文；目录名称没有因此被自动改名。

只保留响应摘要、来源链接及结构元数据，不把完整文章和图片随发行包分发。详见 `data/source_research/adapter_audit_v07_review3.json`、`live_readers_v07_review3.json`、`search_reader_v07_review3.json`。原来 184 条分层调查涉及 19 组站点；本轮另外接入百度百科及 McCormick 的已批准公开页面路径，当前注册表为 21 组，不把新增两组冒充原样本成果。

新版默认其他来源的单源／整轮预算为 25／35 秒，仍可调整、停止和取消。已有工作版本的自定义值保留；若仍是旧 8 秒，慢来源可能继续超时。

## 内嵌视窗的实际边界

本轮实际 Google 图片响应含 `X-Frame-Options: SAMEORIGIN`；百度图片跳转安全验证；Bing 当前响应未声明禁止。网页代码不能把它们全部强制变成可用的原站 iframe。当前实现是真实检测、已有官方凭据时走对应 API、公开元数据可读时本地展示、其余明确解释并保留原站入口。没有把 Google 或百度不可嵌入的状态写成“完全修复”，也不自动解验证或绕过限制。

Google Custom Search JSON API 的现有客户资格／2027-01-01 迁移限制，与 Google Cloud Translation 是两种服务，不能因拥有翻译 API 就认为图片检索 API 已可用。

文字检索的另一项边界是动态页面：本轮 Bing 首屏只返回外壳，没有可提取的结果；Google 文字请求超时。响应允许嵌入时，可以显示原站搜索视窗；否则保留诊断与原站链接。已测试限定主机的安全重定向、公开摘要解析和已审阅正文入口，不能据此声称每次实网请求都可读。
