# v0.7 第五次审查：原位升级与阅读空间

日期：2026-10-30。以下是 `0.7-review5` 交付验收时的记录。用户随后已批准作为 v0.7 commit／push；公开项目说明、MIT 和原始截图见 README。程序仍为 0.7.0。

## 本轮范围

- 以 GitHub 当前 main 的已推送 v0.6 提交 `9e02c9fdaaf6a106e05ed37acfa5928b8640f4d8` 为增量基线，同时支持上轮 v0.7 审查候选。完整包与小补丁使用同一份文件清单、校验和及迁移声明。
- 已发布 v0.6 ZIP 与对应提交在文档、测试夹具打包方式上略有差别。构建时以 `--base-release` 同时读取真实旧 ZIP，记录其 SHA-256 并纳入已知旧文件指纹；保留对未知本机改动的拒绝机制。不是跳过校验。
- 新增标准库升级器 `update.py` 和 Windows／Unix 入口。保持原路径，拒绝运行中的原实例、非目标程序、未知迁移、越界路径、损坏载荷与用户修改过的程序文件。备份受管程序文件、记录各步骤；普通失败回退整条迁移链。
- 数据库、馆藏工作版本、收藏／历史、设置、缓存、次数、媒体与 `.venv` 不进入普通覆盖清单。本轮依赖签名不变，更新时不执行依赖重装；启动流程也改为保留额外包。
- 升级器支持包内连续迁移，最后一次提交安装状态及重启；当前只带真实 v0.6→v0.7 步骤，不虚构 v0.8／0.9 的代码。应用发行记录与馆藏版本管理分开保存。
- 中／西文名称展签移到顶部，默认植物图谱／英文书页，可临时换中文书写／拉丁学名。默认值归属于各工作版本；临时选择可返回／前进，首页尊重已设置默认值。
- 删除正文右侧展签与章节列。章节导航放在全宽正文上方，保留层级链接；没有章节时不额外占位。标题、来源说明、右对齐 Wiki 及语言同处章节标题栏。顶栏链接、标签、选单和按钮统一垂直高度。
- 图片显示检索词。解析可读公开页面中的缩略图、标题、来源链接和公开 JSON-LD／结果属性，不执行网页脚本、调用私有接口或移除安全头；每次最多 20 条。
- 可选浏览器助手通过真实扩展 API 检测原生分屏。只匹配本机图鉴，外站保持独立页面；能用时复用助手自己建立的分屏，不接管用户已有分屏。没有助手或接口不可用时保留普通新标签入口和手动说明；本轮不安装扩展。

## 验证边界

215 项后端测试与 127 项界面检查通过。升级器测试覆盖三版本连续链、后段失败回退、原目录与数据保持、只读预览、修改冲突、校验和、保护路径、符号链接、锁、已有实例、依赖失败恢复。

包级验证已从真实旧发行 ZIP 解压安装、用旧代码初始化两个工作版本及收藏／历史／缓存／媒体，再执行新升级器并启动更新后的应用。v0.6＋小补丁、上轮 v0.7＋新完整包两条路径均通过；每条在第一次启动前核对 14 个个人数据／依赖标记文件保持原始哈希。原目录名、繁体界面设置、阅读字号 23、收藏 1 项、同条目历史访问 2 次、缓存封包和媒体均保留。这是在 Linux 临时目录及外部测试环境中验证的旧安装，未伪称 Windows 原依赖环境已实测。

浏览器使用明确标记的合成正文，检查展签、标题栏、正文宽度、图库关键词、拒绝内嵌后的入口，以及不同尺寸。分屏扩展生命周期使用 API fixture 验证，未安装到浏览器，不等于原生分屏已经完成设备实测。Windows Tcl/Tk、资源管理器拖放、托盘、默认浏览器、DPI 和 120 Hz 仍需本机确认。

Google／百度可能返回动态外壳或验证，公开元数据读取不能保证每个关键词有图。原先验证观察保留日期，不能把合成图片结果当成实际联网成功。独立原站分屏仍需用户在原站完成必要操作。

本轮对 Google 图片仅做一次公开页面读取：`parsley dried flakes` 返回 HTTP 200，但无可提取图片，且为 SAMEORIGIN；没有重复访问百度验证页。该结果保存在 `data/source_research/image_metadata_v07_review5.json`。新增解析能力由公开 HTML 结构的 fixture 验证，不把它宣称为本次 Google 实网图集已成功。
