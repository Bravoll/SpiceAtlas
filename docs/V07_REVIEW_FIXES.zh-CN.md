# v0.7 第二次审查修订

日期：2026-10-29。保留 0.7.0 版本号；不 commit、不 push。比较基线为已同步 v0.6 源码 `9e02c9fdaaf6a106e05ed37acfa5928b8640f4d8`。本轮是在已有 v0.7 工作上修正，不回滚整个项目。

## 正文、图片与诊断回归

v0.6 的自动正文按实际维基映射及请求结果回退。前一候选在固定 2 秒连接轮次中把未完成请求当作失败，又依据被隐藏后的首个按钮选择正文，使本来可读取的 Wiki 变成其他来源或搜索入口。

修复后保留 2000 ms 统一发布及 10 分钟重测：未完成证据是“未确认”，保留上次可用性，初次保持开启；只有确定失败才禁用。Wiki／Commons 浏览器与后台路径独立，任一路径成功即可用；浏览器每项完成即上报，慢请求不扣留兄弟请求的成功。迟到结果仍不修改已发布轮次。自动正文恢复 v0.6 以映射与实际读取为准的流程；只有明确选择“其他来源”才打开卡片板。

真实网络验证：欧芹英文维基取得 72,551 字符 HTML、13 个章节、修订号 1380990209，即使连接报告设为失败仍能得到文章。一次两候选的小图片查询没有有效图像，未掩饰为空；完整新流程从精选文件读取实时 Commons 许可元数据，取得一张 Public domain 图片引用。只记录摘要、链接及许可，正文与照片不进发行包。见 `data/source_research/live_reading_revision_v07.json`。

原图流程等待全部关键词，放大了首图延迟。现在已知精选文件先走实时 imageinfo，其他关键词备用，首个有效结果即可返回；包装检索不会误沿用干叶文件。浏览器直连与后台读取都先查当前版本缓存；刷新明确绕过旧载荷。

## 启动窗口与通知

原固定高度裁掉两排按钮。改为 620×440 初始布局、内容测量后的最小尺寸、自适应换行及主题两列按钮；日志显隐仍记住各自大小。纯布局契约已测试，Windows 实际字体、DPI、托盘外观仍需本机确认。

暂停先广播持久通知，保留约 450 ms 前台送达窗口，再关闭内容入口；暂停后更新同一通知，不增加重复卡。SSE 及时传递，状态轮询补充。继续服务另发带手动重测按钮的通知，在用户重测前暂停自动诊断。暂停时仍可查看状态、收取和关闭通知。真实 HTTP 发行验收另检查事件确实早于内容门禁。

铃铛感应半径为原半径 1.5 倍；展开后按面板和铃铛的并集矩形，四边各加半个半径。离开后完整反向收起，中途返回可逆转；快速靠近立即点击不会误删首条。仍支持触屏、键盘及 Esc。

## 左栏四区与控制位置

当前层级／总数、子集路径／列表、条目／常驻范围及翻页、底部统计明确分区，以短而柔和的线分隔。管理入口仅在设置中。按可用高度计算每页容量，名字与学名适当省略、保留标题；矮窗口进一步收紧控件但保留完整条目和页码。窄屏维持有界目录与普通页面滚动。

子集 [ / ]，条目 , / .，设置可分别自定义。路径留在子集区域顶部，翻页重置该区域滚动位置。区域分页控件使用 sticky；鼠标进入时保留实际按钮和占位，直到移开才用位置差动画归位，并受所属区域下界限制。浏览器检查发现固定化时残留 bottom:0 拉高控件、点击落空，已显式固定捕获高度并清除相对底边约束。

## 缓存与动画

新增的版本内三列操作统计、资源包字典、固定集合预热、六次留存与仅内存的深度一预测，详见 [缓存设计](CACHE_DESIGN.zh-CN.md)。本地资源不参与。

可逆界面使用成对动作：弹窗、阅读抽屉、details、通知栏、原站视窗和控件状态均有回程；通知栏直接复用同一帧序列反向。删除通知和新网站到达是单向事件，分别退场和入场；文字从一个知识状态变成另一个采用真实文字交接，不能把旧来源当作新结果倒放。完整盘点见 [动效方案](MOTION_DESIGN.zh-CN.md)。

## 验收范围

自动化检查、四种真实浏览器容器尺寸、连接／图片实际读取和隔离发行包 HTTP 启停均写入 `data/verification_v07.json`。浏览器预览明确使用合成百科内容，不是在线正文证据。Windows 原生视觉、个人翻译凭据和 120 Hz 仍未实测。多风格预设继续另行研究，本轮没有扩展该工程。
