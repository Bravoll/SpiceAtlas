# 0.6–0.7 交互动效方案与覆盖清单

编制日期：2026-10-29。先完成交互盘点，再按本表实施和验收。0.5 的主题、阅读抽屉和内容淡入是基础；本次扩展到浮层退出、目录操作、状态和长期列表。

## 统一语言

视觉意象是“翻开图鉴、材料落在展台、墨色轻轻晕开”。反馈服务阅读，不让每次操作都变成长片头。0 无应用动画；1 短淡入；2 有方向的常规过渡；3 加入克制的层次、起点和列表错峰。系统减少动态效果始终优先，切到 0 时结束正在运行的效果，并完成其打开／关闭结果。

主要曲线为 cubic-bezier(.16,1,.3,1)，退出用 cubic-bezier(.4,0,1,1)。1 档约 80–120 ms，2 档进入约 180–260 ms、退出 140–180 ms，3 档进入约 280–440 ms、退出 180–260 ms。退出比进入短。主题晕染可到 1 秒，其余不使用循环装饰。

## 快捷键与命令边界

- R = Repeat，重复最近一次适合重复的动作；N = Next、P = Previous 用于当前本地目录翻页。
- Alt+← / Alt+→ 返回／前进；Esc 关闭当前浮层；/ 聚焦本地搜索；? 打开快捷键说明。
- 图片查看器中 ← / → 切换图片。原站 iframe 中的输入属于原站，单键命令不抢占它。
- 输入框、文本区、可编辑区域、下拉多选、IME 组合输入期间不触发单键快捷键。弹窗限制当前可执行命令，避免在输入模型 URL 时翻页。
- 可重复动作登记为命令和方向，不保存旧分页 offset。每次在当前范围、查询、层级、版本重新求值；忙碌时合并一次待重复请求，避免并发把页码算错。
- Esc 是取消当前浮层，不是撤销数据库修改；返回／前进也不是撤销设置或收藏。

## 性能与无障碍标准

优先 transform / opacity 和浏览器原生合成，不用固定 60 FPS 的 JS 循环。高度动画只用于小型 disclosure；列表最多错峰少量节点。滚动时仅更新内存位置，持久化去抖，避免每帧序列化历史。弹窗反复打开／退出、快速翻页和切换 0 档必须可以取消旧动画。

动态效果不作为信息唯一载体。按钮有文字或可访问名称，快捷键在界面可发现；modal 焦点、Escape、错误提示和原生表单能力保留。打印不截到半透明过渡。实际 120 Hz 以上帧率需在相应屏幕验收，本环境不作未测量的帧率承诺。

## 验收记录方式

实施后在 data/verification_v06.json 记录自动化与真实浏览器结果；Windows 原生托盘、后台进程和 GUI 需要用户的 Windows 环境补验，不能用 Linux 上的模拟测试冒充。最终包仍先交付验收，用户明确允许后才 commit / push。

## 0.6 实施结果

共享生命周期位于 `static/interactions.js`，配套样式位于 `static/interactions.css`。图片、设置、帮助、阅读抽屉和展开视窗均使用同一进出流程；关闭中再次打开会从当前计算样式继续，旧回调由 revision 作废。禁用动效会完成相应开关状态。设置保持固定外框；details 保留已有输入节点；通知按可见性变化播放，列表按稳定身份作位置交接，新行单独淡入。

17 项新增 DOM 行为检查包含图片退出仍保持 modal、归还焦点、快速重开、0 档完成、图片键盘作用域、排序、详情保留输入和视窗展开／收回。既有 15 项目录检查与 16 项阅读检查继续通过。真实浏览器补查帮助与图片的开关、英文备注、R 连续翻页、固定导航及同一 iframe 的输入和正文位置保留。录制帧率与 Windows 原生外观不在上述结果之内。


## 0.7：文字、通知与多来源卡片

| 场景 | 3 档设计 | 生命周期与边界 |
| --- | --- | --- |
| 切换界面语言 | 可见旧标题、简介和前导正文按词消散、轻微上浮；新文字清晰显现 | 使用真实内容的 aria-hidden 视觉副本；中文按词分段，最多 3 处、每处 70 片段；900 ms 内清理 |
| 切换知识源或阅读文本 | 旧墨迹收拢模糊，新文字从左向右显现 | 约 350 ms 退场、620 ms 显现；仅真实响应后显示新内容，不用伪文字代替未返回正文 |
| 其他来源卡片到达 | 从右侧轻推入场 | 完整返回后才开始，默认最多 6 卡；已读者停在旧卡时不强拉横向位置 |
| 铃铛展开 | 铃铛变关闭符号，面板从右上角展开，卡片短错峰 | 悬停、触屏点击、键盘均可进入；通知不会自动消失 |
| 关闭当前通知 | 首卡短退场，其余按位置差上移 | 关闭按钮保持原位、稳定 DOM 节点；重复轮询不复活已关闭卡片 |

0 档和系统 reduced motion 始终优先，取消已拥有的动画并立即清除文字副本；页面离开也清理。文字和来源过渡在操作完成后撤销状态，普通重绘不反复播放。可读正文始终保持真实 HTML 与链接。

没有用新字体或样式假称历史来源。多种设计风格、古典／神话预设和图钉纸条拟物效果按用户要求暂缓，本次没有提前制作风格切换，也没有声称已完成软件系统风格调查。120 Hz 仍待目标设备测量。

## 第二次审查：正反向规则

可逆界面优先使用同一几何路径的回程，允许不同持续时间；中断时从当前画面继续，旧回调由代次作废。

| 交互 | 正向 | 反向／中断 |
| --- | --- | --- |
| 图片、设置、帮助浮层 | 淡入＋缩略起点或抬起 | 同一路径收拢并淡出；结束后才撤销 modal |
| 阅读抽屉 | 从右侧进入 | 沿右侧退出；保存成功再完成 |
| 通知栏 | 从铃铛后展开 | 同一 Web Animation reverse；移回可中途倒转 |
| details、说明面板 | 高度／透明度展开 | 反向收起，保留既有输入节点 |
| 原站视窗放大／收回 | 同一 iframe 抬入顶层 | 动画后回原容器，恢复原滚动 |
| hover、按下、选择 | 颜色、短位移和缩放 | CSS 返回原状态，不残留变形 |
| 翻页驻留控件 | 指针进入后锁定捕获位置 | 指针离开后由位置差归位；固定高度以免继承 bottom 拉伸 |
| 列表排序 | 根据真实前后位置位移 | 反向排序自然产生相反位移 |
| 图像上一／下一张 | 与方向一致的横向交接 | 相反方向参数产生逆向位移 |

新资料到达、通知永久关闭、保存反馈和点击墨迹没有同一业务动作的逆操作，保持各自的一次性入场／退场。语言与知识源更换是不同内容的交接，使用真实旧／新文本，不把旧资料倒放冒充新响应。页面刷新或主动取消仍清理旧视觉层。

通知感应在铃铛边缘外扩半径的一半；展开后按全部元素边界外扩同样距离，矩形之外才收起。靠近后立即点击保护只用于避免误删，不妨碍后续有意连续关闭。分页路径及按钮在自己的有界区域中常驻，短窗口减少每页条目数，避免动画改变整体高度。

快捷键补充：默认 [ / ] 翻子集，, / . 翻条目，四键可在设置修改；N/P 继续兼容。最终当前证据以 `data/verification_v07.json` 为准，前述 0.6 检查数量作为历史保留。


## 第三次审查：当前采用的轻量方案

前述消散副本、全文模糊／裁切及整页主题揭示已替换。主题即时应用，仅按钮附近小光晕；第三档文字按英文词、中文单字、独立标点，最多同时 64 单元，只作用于短标题和少量短段落。表格与长文正常排版，取消后拆掉临时 span。下拉选单在支持 base-select 的浏览器中渐进增强开／关动效，其他环境保留原生交互。手法比较、性能取舍及一手依据见 [本轮动效调查](MOTION_RESEARCH_v0.7_review3.zh-CN.md)。旧描述仅作为迭代记录，不代表仍运行旧特效。
