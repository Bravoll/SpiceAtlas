# 0.6 交互动效方案与覆盖清单

编制日期：2026-10-29。先完成交互盘点，再按本表实施和验收。0.5 的主题、阅读抽屉和内容淡入是基础；本次扩展到浮层退出、目录操作、状态和长期列表。

## 统一语言

视觉意象是“翻开图鉴、材料落在展台、墨色轻轻晕开”。反馈服务阅读，不让每次操作都变成长片头。0 无应用动画；1 短淡入；2 有方向的常规过渡；3 加入克制的层次、起点和列表错峰。系统减少动态效果始终优先，切到 0 时结束正在运行的效果，并完成其打开／关闭结果。

主要曲线为 cubic-bezier(.16,1,.3,1)，退出用 cubic-bezier(.4,0,1,1)。1 档约 80–120 ms，2 档进入约 180–260 ms、退出 140–180 ms，3 档进入约 280–440 ms、退出 180–260 ms。退出比进入短。主题晕染可到 1 秒，其余不使用循环装饰。

## 快捷键与命令边界

- R = Repeat，重复最近一次适合重复的动作；N = Next、P = Previous 用于当前本地目录翻页。
- Alt+← / Alt+→ 返回／前进；Esc 关闭当前浮层；/ 聚焦本地搜索；? 打开快捷键说明。
- 图片查看器中 ← / → 切换图片。原站 iframe 中的输入属于原站，单键命令不抢占它。
- 输入框、文本区、可编辑区域、下拉多选、IME 组合输入期间不触发单键快捷键。弹窗限制当前可执行命令，避免在输入模型 URL 时翻页。
- 可重复动作登记为命令和方向，不保存旧分页 offset。每次在当前范围、查询、层级、版本重新求值；忙碌时合并一次待重复请求，避免并发把页码算错。
- Esc 是取消当前浮层，不是撤销数据库修改；返回／前进也不是撤销设置或收藏。

## 性能与无障碍标准

优先 transform / opacity 和浏览器原生合成，不用固定 60 FPS 的 JS 循环。高度动画只用于小型 disclosure；列表最多错峰少量节点。滚动时仅更新内存位置，持久化去抖，避免每帧序列化历史。弹窗反复打开／退出、快速翻页和切换 0 档必须可以取消旧动画。

动态效果不作为信息唯一载体。按钮有文字或可访问名称，快捷键在界面可发现；modal 焦点、Escape、错误提示和原生表单能力保留。打印不截到半透明过渡。实际 120 Hz 以上帧率需在相应屏幕验收，本环境不作未测量的帧率承诺。

## 验收记录方式

实施后在 data/verification_v06.json 记录自动化与真实浏览器结果；Windows 原生托盘、后台进程和 GUI 需要用户的 Windows 环境补验，不能用 Linux 上的模拟测试冒充。最终包仍先交付验收，用户明确允许后才 commit / push。

## 0.6 实施结果

共享生命周期位于 `static/interactions.js`，配套样式位于 `static/interactions.css`。图片、设置、帮助、阅读抽屉和展开视窗均使用同一进出流程；关闭中再次打开会从当前计算样式继续，旧回调由 revision 作废。禁用动效会完成相应开关状态。设置保持固定外框；details 保留已有输入节点；通知按可见性变化播放，列表按稳定身份作位置交接，新行单独淡入。

17 项新增 DOM 行为检查包含图片退出仍保持 modal、归还焦点、快速重开、0 档完成、图片键盘作用域、排序、详情保留输入和视窗展开／收回。既有 15 项目录检查与 16 项阅读检查继续通过。真实浏览器补查帮助与图片的开关、英文备注、R 连续翻页、固定导航及同一 iframe 的输入和正文位置保留。录制帧率与 Windows 原生外观不在上述结果之内。
