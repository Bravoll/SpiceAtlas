# v0.7：清新图鉴的文字过渡与性能调查

日期：2026-10-29。范围仅是现有清新风格的第三档动效，不是多风格预设调查。先比较手法与约束，再选择本轮实现。

## 调查依据与判断

web.dev 的动画性能指南建议优先使用 transform 与 opacity，其他属性应核查是否触发布局或重绘。Apple 的 Motion 指南强调短、准确、可以中断，并与用户的操作方向一致。以下“适合图鉴”的判断是本项目的设计推论，不是这些文档对香料网站的推荐。

| 手法／叙事意象 | 对本图鉴的用途 | 性能与阅读代价 | 本轮决定 |
| --- | --- | --- | --- |
| 打字机：删除旧字、打出新字 | 短展签、简短引语，有书写与记录感 | 全文逐字会等待太久；修改长度会反复排版，破坏选区与滚动 | 不应用于全文；保留为以后短标题的候选 |
| 翻字牌：词或字沿横轴翻出 | 英文词／汉字的切换清晰，略有展签翻页的感觉 | 真正逐帧改变字宽会牵动段落；大量三维层也有成本 | 采用短而柔和的单次翻入，不计算动态宽度 |
| 墨迹显现：文字逐渐清楚 | 植物标本与纸张语境协调 | 大面积 blur、clip-path 和整篇截图消耗较高，还可能遮住表格 | 来源变化只对少量短文字轻移、显现，不做整页遮罩 |
| 魔法书式粒子消散与重组 | 适合强叙事标题或章节开场 | 大量碎片、随机路径、视觉副本容易重影，分散阅读注意 | 本轮移除旧大块文字副本，不制作粒子系统 |
| 纸页揭示／整页颜色晕染 | 少量主题氛围提示 | 整页 View Transition 要捕获页面；超大渐变与混合模式会拖慢响应 | 颜色在当前输入事件立即变化，装饰限于按钮附近的小光晕 |
| 下拉选单展开／反向收起 | 过滤器保持熟悉的原生交互 | 自制 JS 选单需要重新处理键盘、焦点及触屏 | 支持时用浏览器 base-select、picker、starting-style 渐进增强；不支持时保留系统选单 |

`steps()` 能表达离散步进，但不是“任意 HTML 的无成本打字机”；多语言的单词／字素边界也需要明确规则。根据用户本轮约定，本版直接采用英文词、中文单字、独立标点；不把浏览器 Ctrl+Shift 的平台相关选词结果当作固定跨平台标准。未来增加其他语系时可用 Intl.Segmenter 补充细分。

## 已采用的约束

- 主题同步应用，无整页截图等待；360 ms 局部光晕只动透明度与缩放，面积不超过约 420×260 px，不做混合模式或模糊。
- 同时最多 64 个文字单元。只选短标题和少量位于可见区域的短段落，表格、代码及长正文不切成动画字块。
- 语言约 240 ms、来源约 180 ms，错峰延迟最多 140 ms。新内容按真实响应呈现，不为了动画延迟数据。
- 包裹真实文本节点，保留原链接和表格；结束或取消后拆掉临时 span。没有复制一层仍与原文重叠的假正文。
- 不动画宽高或每字位置；新内容只做必要的一次排版。连续切换使旧代次失效，主题保存和语言保存分别排队，迟到响应不得覆盖新选择。
- 0 档及系统减少动态效果即时完成状态，文字清理后保持可读。原有弹窗、抽屉、通知进退仍保留成对动效。

浏览器支持 base-select 时，下拉的开／关可分别淡入、反向淡出；旧浏览器的系统选单无法由网页统一动画，不用重写一个不完整的替代品。

## 验收与限制

行为测试检查主题在保存回复前已改变、不调用整页 View Transition、文字预算、单字分段、表格和链接节点保持，以及取消后文本完整。真实 Chrome 检查主题、Wiki 语言、下拉控件和延迟正文；滚动测试从加载中 1229 px 到完成后仍为 1229 px。

这证明了这些行为，没有测出任何设备的 120 Hz 帧率或 GPU 利用率。Windows 显示、不同浏览器的原生 picker 和目标高刷屏仍需本机检验。
