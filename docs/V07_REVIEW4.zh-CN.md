# v0.7 第四次审查：部分连接与并发阅读

日期：2026-10-30。版本保持 0.7.0，继续供用户审查，不 commit、不 push、不部署。

## 本轮修复

| 触发条件 | 旧行为 | 修复后 |
| --- | --- | --- |
| 中文优先、Wiki 链接仍在加载，用户选择 GBIF／Bing 等其他来源 | 非 Wiki 阅读也等待 Wiki；刷新还会额外重查 Wiki | 等待只用于需要 Wiki 的正文；其他来源独立加载、独立刷新 |
| 英文语言链接查询超时 | 跳过独立中文搜索 | 在整轮 30 秒预算内继续尝试中文查找，保留英文失败诊断 |
| 中文名称与学名两个查询中，一个失败 | 丢弃另一个成功查询 | 处理成功结果，并将部分失败记为未确认 |
| 强制刷新或映射过期后断网 | 丢掉之前发现的中文／其他语言链接 | 保留已验证映射；新成功数据优先，60 秒后可重试；不把失败当作确认不存在 |
| 错误候选摘要提到目标植物 | 仅凭相关学名可能接受另一植物 | 双方均有 Wikidata 身份时，冲突即拒绝；目录无身份时可采用英文锚点身份 |
| 等待详情缓存时切换到另一条目 | 缓存未命中后可能用新条目搭配旧网址请求 | 固定请求所属条目，并在缓存返回后检查阅读代次；过期则不发后续请求 |
| 翻译仍在查缓存／等待服务时返回原文 | 旧请求仍可能启动或更新翻译状态 | 每次显示模式选择产生翻译代次；旧缓存未命中不再启动服务，已发出的旧回复不覆盖当前选择 |
| 当前没有可选服务 | 正文的忙碌标记残留 | 显示终态说明并清除忙碌标记 |

本轮不扩大设计风格范围；保留第三次修订的有界文字单元和即时主题切换。已发出的第三方请求仍可能在服务端完成；本轮保证的是过期任务不再发起后续请求，也不覆盖当前阅读，不能承诺撤回已执行的外部服务操作。

## 验证方法

`tests/test_v07_followup.py` 六项回归覆盖部分查询失败、离线刷新、过期映射及身份冲突。`tests/reading_concurrency_acceptance.cjs` 六项回归控制缓存、语言和翻译回复顺序，检查非 Wiki 独立加载、过期详情请求、原文选择及忙碌终态。新增用例均先在第三次代码上复现失败，再修复。

全部自动检查数量与结果见 `data/verification_v07.json`。真实 Chrome 使用明确标记的合成 API，检查中文界面下 GBIF 选择及刷新、Wiki 简繁切换、正文加载终态和页面无横向溢出；不能把合成正文当作联网抓取成果。发行 ZIP 另在隔离目录检验首次启动和暂停／继续流程。

## 沿用的边界

本轮没有重复请求 Google／百度验证页面；第三次实际网络结果仍是历史证据，不能承诺原站 iframe 可用。Windows 原生窗口、DPI、设备音频和 120 Hz 仍待本机验收。个人翻译凭据未调用。原来多设计风格预设、完整作者 About 和 GitHub 更新器仍不在本轮范围。

前轮说明：[第三次修订](V07_REVIEW3.zh-CN.md)、[动效调查](MOTION_RESEARCH_v0.7_review3.zh-CN.md)。实现继续按 MediaWiki 的 [Langlinks 接口](https://www.mediawiki.org/wiki/API%3ALanglinks) 读取跨语言关联，部分失败和缓存保留是本项目的可靠性处理。
