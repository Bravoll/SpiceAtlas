## 本版实现

1. `desktop/gui.py`：同一按钮切换日志显隐，分别记住紧凑／展开尺寸；窗口名统一为“香料图鉴 - Spice Atlas”。日志面板继续接收后台输出，保留最近 5000 行，文件日志继续记录。
2. `desktop/win_native.py`、`desktop/interactions.py`：每次修改托盘数据都保留 tooltip 标志；单击延迟到系统双击判定结束才切换窗口，双击取消待定单击并打开浏览器；处理重复的原生选择事件。菜单名称为显示／隐藏界面，增加暂停／继续。
3. `atlas/runtime.py` 和 launcher control：暂停为应用级软暂停，不挂起操作系统进程。保留 GUI、进程和端口，拦截新内容 API；诊断与导入暂停，只恢复由本次暂停挂起的导入任务。已有请求按边界检查或有界超时结束。每实例控制密钥不进入状态、命令行或日志，禁止控制别的本机实例。
4. 终端桥接：HTTP、来源请求／响应、状态和界面操作标识写入 launcher 捕获的 stderr。浏览器额外记录跨站资源的主机与类型，网页事件桥不记录查询文本或设置值，HTTP 追踪省略认证头和请求正文；敏感字段与 URL 密钥二次脱敏。不会产生递归的浏览器资源日志。
5. `atlas/health.py`：首个页面激活单个 2000 ms 轮次，后台与浏览器共用 round_id；到点统一发布，拒绝迟到结果，结束 600 秒后再检测。首次保持乐观开启，后续检测保留上一轮状态。5 秒页面读取仅查询报告，不连续重启测试。
6. `static/notifications.js`：固定铃铛、数字、悬停展开、原位关闭首条、后续卡片上移。维护稳定节点和已关闭 ID，旧轮询不能让已关闭通知复活；触屏点击、键盘和 Esc 可用。
7. `static/text_motion.js`：3 档语言切换采用旧文字消散＋新文字显现，来源切换采用墨迹展开。只复制真实文字到 aria-hidden、不可点击的短暂视觉层，不生成伪学名；真实正文链接和可访问文本保留。0 档、系统减少动态效果以及页面离开会清理视觉层。
8. `atlas/other_sources.py`、`static/source_board.js`：完整文章卡片按异步完成顺序横排，支持独立滚动、目录及正文链接；默认 8 秒／20 秒／6 卡片。超过上限、停止、切换和断开会取消余下任务。详见来源调查，候选与已验证可读分开记录。

## Windows 本机重点验收

- 新目录解压启动：查看阶段进度，同一详细按钮展开／收起；窗口名正确。网页切条目、换来源、调设置，确认终端继续输出且不出现输入密钥。
- 悬停托盘有应用名；单击仅切窗口，双击仅开网页。右键可显隐窗口、暂停／继续、打开日志和停止。任务栏重启、DPI 和双击速度应在本机检查。
- 暂停后网页显示提示，新内容请求返回暂停状态；进程和端口仍在，继续时同实例恢复。确认停止并退出仍能清理自己创建的进程。
- 首轮 2 秒内不出现逐项禁用／恢复，结束时统一更新；10 分钟后的变化通知保留到手动关闭。铃铛原位连续关闭两条，指针无需追着卡片移动。
- 3 档切语言和来源，观察两种文字变化；切 0 或系统减少动态效果，不残留重影。其他来源卡片逐张出现，旧卡片独立阅读，横滚查看、停止和换条目不串页。
