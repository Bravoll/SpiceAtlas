# v0.2 开发记录

日期：2026-10-27（澳大利亚东部夏令时间）。

## 本次需求

沿用已经认可的材料配色和展签风格，接入重点知识来源与图片，提供来源跳转，并保留嵌入正文内部的超链接。

## 实现选择

- 本地 FastAPI 后台与单页面前端；目录 13 项。
- Wikimedia Action API 作为可验证、可实际调用的正文来源。
- Commons 作为无需用户密钥的图片来源。
- 百度百科与图片保持明确外链；不依赖无法核实的旧接口或他人 appid。
- Bing 图片保持外链，因为 Search API 已退役。
- Google 仅为既有 API 客户保留适配器；没有密钥时明确提示。
- 其他专业资料显示简短整理提示和出处，不声称已经自动抓取原站全文。
- 中英文物种／商品范围不同的条目增加提示。

## 内容处理

- 支持维基重定向与固定版本。
- 正文、重点章节与目录分别输出。
- 相对超链接改为绝对来源地址。
- 章节和引用使用来源命名空间；完整模式中的脚注在本地跳转。
- 重点模式没有包含的目标改为跳转原站锚点。
- 图片独立展示作者、许可、原图与来源页。
- 译文对模型文本转义；原来源链接通过占位符恢复。

## 验证范围

已运行内容清理、锚点、引用、缓存失败回退、来源能力状态、原料形态验证、路径验证和应用路由测试。JavaScript 执行语法检查。

真实来源获取记录见 data/fetch_manifest.json。Google 实际结果与用户 LM Studio 模型未做端到端验证。

托管预览的隔离环境不包含本项目 Python 虚拟环境，无法执行该后台；没有通过安装浏览器、修改网络权限或以伪结果替代的方式掩盖这一限制。交付为可在用户电脑运行的本地项目，真实浏览器视觉验收待本地进行。

## 后续扩展

- 历史事件的结构化提取与人工核实。
