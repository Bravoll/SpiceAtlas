# Supplement C provider research

Checked 2026-10-29 UTC. These are supplemental search-service results. They are not direct Google or Bing first pages. No service was authenticated or scraped and no app code was changed.

## Provider routes and limits

| Provider | Verified documentation / observed public route | Useful role | Limits observed in this research |
|---|---|---|---|
| Kew POWO | [Search help](https://powo.science.kew.org/search-help), [About](https://powo.science.kew.org/about). Repeated observed record routes use `https://powo.science.kew.org/taxon/<IPNI-ID>` or `/taxon/urn:lsid:ipni.org:names:<IPNI-ID>`. [Kew Swagger candidate](https://species-ws.data.kew.org/openapi). | Global taxonomic status, synonyms, broad distribution; selected accounts contain explanatory material. IPNI IDs are useful cross-provider keys. | Search exposed the Swagger page, but its body was client-rendered and no API schema or requests were tested. Several POWO opens returned 403; search discovery therefore does not guarantee later page retrieval. Resolve a verified ID rather than inventing a URL from a name. Genus-list hits can include the target name without being a species account. |
| WFO Plant List | Official [WFO source repository](https://github.com/worldflora/wfo-plant-list), [GraphQL examples](https://github.com/worldflora/wfo-plant-list/blob/main/www/gql_index.php), and [deployment documentation](https://plant-list-docs.rbge.info/manual/current_deployments.html). They identify live `https://list.worldfloraonline.org/` and GraphQL `https://list.worldfloraonline.org/gql`. Observed taxon routes use `https://www.worldfloraonline.org/taxon/wfo-<10 digits>`. | Name reconciliation, accepted usage, synonyms and taxonomic identifiers. | Live root timed out in this retrieval; API operations were not tested. Official documentation distinguishes production and test deployments. Search sometimes returned stage/test hosts and session-suffixed URLs; avoid shipping those without canonical verification. For large matching jobs, the official repository recommends local deployment/data download. |
| IPNI | [About](https://www.ipni.org/about), especially Tools; [FAQ](https://ipni.org/faq). Observed name route `https://www.ipni.org/n/<ID>`. About documents RDF via a record's `/rdf` suffix and LSID content negotiation, and links [Names Reconciliation](https://namematch.science.kew.org/). | Nomenclature, author, original publication, type references, stable LSID/name IDs. | IPNI states that a general public API is not yet available. Its reconciliation root timed out here. FAQ says IPNI does not supply accepted-name opinions or global distributions; use POWO for those. Names can be missing or delayed and orthographic corrections occur. Do not represent nomenclature alone as food-use evidence. |
| GBIF | [Species API](https://techdocs.gbif.org/en/openapi/v1/species), [taxonomy interpretation](https://techdocs.gbif.org/en/data-processing/taxonomy-interpretation). The latter documents `https://api.gbif.org/v2/species/match`, scientificName/checklistKey inputs and identifier matching. | Machine-readable taxonomic matching and provenance; preserve match diagnostics and checklist identity. | Current official docs identify Catalogue of Life XR as primary and say old GBIF Backbone builds are discontinued, with legacy IDs preserved. Optional checklistKey determines taxonomy; an omitted checklist can use the legacy backbone. Fuzzy or higher-rank matches require review. API was documented, not executed in this subtask. |
| Australian APNI/APC and ALA | [APNI](https://www.anbg.gov.au/apni/), [IBIS](https://www.anbg.gov.au/ibis/). [ALA Hemigenia account](https://bie.ala.org.au/species/https%3A/id.biodiversity.org.au/node/apni/2895843) links persistent name/instance/node identifiers. | Strong regional authority for Australian spellings, names, concepts and orthographic variants. | APNI names and APC accepted concepts have different roles. ALA displayed the explicit pimelifolia/pimeleifolia relationship; retain that relationship rather than treating a fuzzy spelling match as proof. No programmatic API was tested. |
| Regional floras and Extension | Observed [NSW PlantNET route](https://plantnet.rbgsyd.nsw.gov.au/cgi-bin/NSWfl.pl?lvl=sp&name=Coriandrum~sativum&page=nswfl), [NCSU cultivar profile](https://plants.ces.ncsu.edu/plants/capsicum-annuum-conioides-group/common-name/facing-heaven/), [RBGE Bhutan treatment](https://websites.rbge.org.uk/URC/bhutanumbels/Sinocarum.htm). | Identification keys, regional distribution, cultivation and explanatory material. | These are observed public URL patterns rather than documented bulk APIs. Preserve returned record IDs/slugs and verify exact taxon/cultivar scope. A regional absence or presence says nothing by itself about global rarity. |
| Institutional specimen portals | MNHN `/institution/<institution>/collection/<collection>/item/<specimen>` and [Illinois Natural History Survey collection](https://biocoll.inhs.illinois.edu/portal/collections/list.php?comingFrom=harvestparams&country=Peru&db=67&page=3). | Primary specimen/type evidence, particularly where popular explanatory material is absent. | An herbarium label or specimen list may preserve historical spellings and need not express current accepted taxonomy, edible use or conservation status. Search-list URLs can be less stable than individual specimen records. |

## Match cautions retained in supplement_c.json

- **Phlomis bracteata** and **Satureja secondaireana**: no suitable exact-name institutional or explanatory source selected. Nursery commerce, mirror pages and near-name species were excluded.
- **Isodichyophorus chevalieri**: the exact historical spelling occurs in Guinea-Bissau's national biodiversity plan hosted by [FAO](https://faolex.fao.org/docs/pdf/gbs157123.pdf). Kew's Isodictyophorus chevalieri is a synonym of Coleus reticulatus, but that does not itself establish equivalence with the baseline spelling.
- **Piper scutaespicum**: exact-name institutional collection evidence was found at Illinois and STRI. The near-name Piper scutispicum was not substituted.
- **Ligusticum peloponnesiacum**: the exact Kew spelling carries author Pall.; the baseline sample has no author. Similar names with different authors/spellings remain a review concern.
- **Phlomoides cuneata** and **Thymus marandensis**: primary genus accepted-species lists explicitly include the names. The former's species URL was obtained by clicking Kew's list but returned 403; the latter's genus open returned 403.
- **Prunella laciniata × vulgaris**: Kew explicitly supplies that hybrid formula for Prunella × intermedia, corroborated by a primary Croatian flora paper.
- **Hemigenia pimelifolia**: ALA and a Western Australia government journal explicitly document pimeleifolia as the corrected orthographic form.

## Audit scope

All 61 assigned entries were queried. The 23 entry-search batches contain 76 queries, including targeted refinements. 59 entries have 1–3 selected URLs; 2 have explicit no-suitable-result status. Search tool responses interleave batched queries, so the file keeps each shared batch result pool and separately records manually matched selections. Source metadata includes titles, URLs, domains, tool kind, query and ISO timestamp. Full article bodies are not stored.

Neither taxonomy nor a specimen is evidence of edibility, culinary suitability, popularity, rarity or conservation status. Culinary mixtures also require mixture-specific sources; a botanical page for one ingredient does not establish the blend's composition.
