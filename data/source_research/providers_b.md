Checked 2026-10-29 (UTC). Assignment: sample_index % 3 == 1. All 61 assigned entries were searched: 61 initial queries in 16 calls, plus 13 verification queries in 6 calls. Selected 112 source links. Provider research added 9 documentation queries. The JSON records only titles, URLs, short relevance notes, timestamps and limitations.

These are supplemental search-service results. They are not Google's or either Bing edition's first-page results. A search result title/excerpt is a discovery observation, not a successful full-page fetch. Botanical taxonomy, aromatic chemistry, medicinal history and conservation status do not establish culinary use or culinary rarity.

Kew's [POWO about page](https://powo.science.kew.org/about) explains why old and accepted names can differ, how source material is attached to the accepted backbone name, and why identifiers ending in `-4` are temporary WCVP identifiers rather than valid IPNI IDs. The pipeline should preserve the input label separately from the returned accepted name. Do not create an IPNI link from a temporary `-4` identifier.

WFO's [identifier concepts](https://github.com/worldflora/wfo-docs/blob/main/docs/concepts.md) distinguish a name ID from a release-specific taxonomic usage. Store the WFO ID and data release when reproducibility matters. The official publisher also suggests a local instance when bulk matching would burden the public service.

For SANBI PlantZAfrica, NZPCN, Flora of New Zealand, HortFlora, national biodiversity portals and university extension articles, the successful records in the JSON are useful HTML/PDF entry links. This pass did not establish supported API contracts for those providers. A conservative resolver can use institution-restricted discovery, check the returned scientific name and publisher, and retain the actual article URL with its retrieval date. URL guesses based solely on the input name are not evidence.
